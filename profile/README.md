# EWHA-VIDI 🔍

> **이화여자대학교 캡스톤디자인 34조 [삼초컷]**  
> **VIDI**: Viral Detection Intelligence (유튜브 댓글 관계 분석 기반 은닉형 조직적 바이럴 탐지 시스템)

---

### 💡 Project Overview
**VIDI**는 유튜브 댓글의 익명 계정 활동과 시간적·구조적 관계를 분석하여, 고도화된 은닉형 조직적 바이럴 의심 패턴을 발굴하고 조사를 지원하는 지능형 시스템입니다.

- **복합 관계 분석**: 단순 텍스트 유사도 비교를 넘어 계정 간 상호작용, 활동 시점, 트래픽 패턴을 종합적으로 분석해 조직적 행동 후보군을 자동 발굴합니다.
- **설명 가능한 탐지(XAI)**: 머신러닝 기반 이상 패턴 탐지와 네트워크 분석을 결합하여, 단순 판정이 아닌 명확한 근거와 시각적 지표를 함께 제공합니다.
