# EWHA-VIDI

> 이화여자대학교 캡스톤디자인 34조 **삼초컷**
> **후기인 척하는 Viral, VIDI는 봤어요**

VIDI는 광고 표시 없이 후기처럼 쓰인 유튜브 댓글에서 **조직적 바이럴 의심 후보**를 찾아,
근거와 함께 조사관에게 넘기는 조사 지원 도구입니다.

## 왜 만드나요

> "자발적인 소비자 후기로 위장한 댓글형 광고는 일반 의견과 구분하기 어렵다.
> 기관의 모니터링이 이루어지고 있지만, 불특정 다수가 작성하는 방대한 게시물과 댓글을
> 모두 확인하는 데에는 한계가 있다."
>
> — 공정거래위원회, 「2026년 공정거래백서」

댓글 하나만 보면 평범한 후기입니다. 여러 계정이 비슷한 문장을, 비슷한 시점에,
같은 제품에 대해 남길 때 비로소 패턴이 보입니다. VIDI는 이 패턴을 찾아 사람이 빠르게
확인할 수 있게 정리합니다.

## 어떻게 찾나요

| 신호 | 보는 것 |
| --- | --- |
| 계정 신호 | 같은 계정 묶음이 여러 영상에 반복해서 등장하는지 |
| 문장 신호 | 표현만 바꾼 같은 구조의 문장인지 |
| 시간 신호 | 영상 업로드 직후 등 짧은 시간에 몰리는지 |

세 신호를 합쳐 의심 점수를 매기고, 원래 언급이 많은 인기 제품은 인지도 기준선으로 보정합니다.
군집마다 관련 법령(표시광고법, 화장품법 등)의 요지와 원문 링크를 함께 보여줍니다.

**점수는 패턴의 강도일 뿐이며, 광고인지는 사람이 판단합니다.**
VIDI의 결과는 특정 브랜드나 제품에 대한 판정이 아닙니다.

## 사용 흐름

```text
관리자   탐지 후보 → 1차 검토 ─(전달)─┐
                                      ▼
조사관   조사 후보 → 후보 상세 → 증거 상세 → 사람이 판단
                       └──── 피드백 ────→ 관리자
```
